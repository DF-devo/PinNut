\# 🥜 PinNut



> Лёгкий планировщик задач с локальным хранением данных и визуальной приоритизацией.

>

> Работает полностью на фронтенде — без сервера, регистрации и задержек.



\---



\## ✨ Возможности



\* Создание и редактирование заметок

\* Два типа заметок:



&#x20; \* \*\*Текст\*\* — позволяет записать всю необходимую информацию в свободной форме

&#x20; \* \*\*Список\*\* — позволяет создавать заметки из отдельных пунктов

\* Отметка пунктов списка как выполненных

\* Изменение порядка пунктов в списке

\* Настройка приоритета заметок

\* Закрепление важных заметок

\* Фильтрация и сортировка заметок

\* Установка дедлайна

\* Назначение пользовательского цвета для заметок

| Компонент           | Технология                                   |

\## 📖 Как пользоваться



1\. Нажмите \*\*«+ Заметка»\*\* для создания новой заметки.

2\. Выберите тип заметки: \*\*Текст\*\* или \*\*Список\*\*.

3\. Заполните приоритет и текстовые данные заметки.

4\. При необходимости укажите теги, дедлайн и пользовательский цвет.

5\. Для фильтрации заметок по тегам выберите нужный тег в поле фильтрации.

6\. Для сортировки по дате или приоритету выберите соответствующий вариант в выпадающем меню.

7\. Чтобы отметить заметку типа \*\*Список\*\* как выполненную, отметьте все её пункты выполненными.

8\. Для закрепления, редактирования или удаления заметки используйте кнопки \*\*📍\*\*, \*\*✏️\*\* и \*\*🗑️\*\*, расположенные в нижней части карточки.

9\. Для изменения цветовой темы интерфейса откройте меню настроек \*\*⚙️\*\*.
