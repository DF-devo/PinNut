# 🥜 PinNut
> Легкий планировщик задач с локальным хранением и визуальной приоритизацией.  
> Работает полностью на фронтенде, без сервера, регистрации и задержек.

---

### ✅ Реализовано (MVP 30%)
- 📝 Создание заметок (текст, теги, цвет фона, приоритет, дедлайн)
- 📌 Закрепление важных задач (всегда отображаются сверху)
- 🔍 Фильтрация по тегам в один клик
- 📊 Сортировка по дате создания и приоритету
- ⏱ Цветовой индикатор срочности (зелёный → жёлтый → красный → просрочено)
- 💾 Автосохранение в `localStorage` (данные не теряются при перезагрузке)

### 🚀 В планах (70%)
- 📅 Календарь для долгосрочного планирования
- 🤖 ИИ-ассистент для разбивки сложных задач
- 🎨 Рисование и вставка изображений прямо в заметки
- 🔔 Звуковые уведомления при выполнении задач

---

### 🛠 Стек технологий
| Компонент | Технология |
|-----------|------------|
| Фреймворк | React 19 + TypeScript |
| Сборка | Vite 8 |
| Стейт-менеджмент | Zustand 5 |
| Хранение | `localStorage` (абстракция `StorageService`) |
| Стилизация | CSS Variables + Inline-styles |
| Процессы | Git Flow, PR-ревью, ручные QA-чеклисты |
